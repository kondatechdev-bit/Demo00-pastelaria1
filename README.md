## ✅ Como usar este kit

### 1. Ver o site-demo (no celular)
- Abre o link do site de links ou do projeto específico 
- Abre o Acode ou Trebeditor
- Abre o ficheiro `site-demo/index.html`
- Toca em "Visualizar" / "Run" → vê o site completo
- Os 3 ficheiros (`index.html`, `style.css`, `script.js`) devem ficar **na mesma pasta**

### 2. Testar o app Python (Pydroid3)
- Instala o Pydroid3 da Play Store (grátis)
- Copia o conteúdo de `app-pastelaria/main.py` para um novo projeto
- Clica ▶ Run → menu interactivo aparece
- Os dados gravam em `vendas.json` no mesmo directório

### 3. Imprimir a proposta comercial
- Abre `docs/proposta-comercial.html` no navegador
- Clica no botão 🖨️ no canto superior direito
- Escolhe "Guardar como PDF" ou imprime directamente

### 4. Estudar o pitch
- Lê `docs/pitch-abordagem.md`
- Adapta a mensagem WhatsApp com os dados das tuas empresas-alvo
- Segue a meta semanal sugerida
